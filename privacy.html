개인정보 처리방침

시행일 2026년 11월 21일 · 회원가입 없음 · 광고·분석 도구 없음

한 줄 요약

무료 모드에서는 어떤 내용도 서버로 보내지 않습니다. 입력한 대본·사진·영상은 이 브라우저 안에서만 처리되고, 만든 영상 파일도 기기에 저장됩니다. Pro 기능을 직접 연결한 경우에만 사용자가 고른 제공자에게 필요한 문장이 전송됩니다.

이름, 전화번호, 이메일, 위치, 연락처, 결제 정보는 수집하지 않습니다. 계정도 만들지 않습니다.

2. 무료 모드에서 서버로 가는 것

없습니다. 대본 생성, 자동 비주얼 그리기, 테마 그리기, 배경음 합성, 영상 녹화(MediaRecorder), 자막 생성이 모두 브라우저 안에서 실행됩니다. 앱을 열 때 외부에서 불러오는 파일도 없습니다(폰트·스크립트 모두 앱에 포함).

무료 모드의 성우 미리듣기는 기기의 음성 엔진(브라우저 speechSynthesis)을 쓰며 서버로 가지 않습니다. 이 소리는 미리듣기 전용이라 .webm 영상 파일에는 녹음되지 않습니다.

무료 AI 대본 맛보기(선택). 무료 모드에서 '무료 AI 대본 맛보기'를 누를 때만 주제·말투·플랫폼이 프롬프트로 전송됩니다. 무료 체험은 Cloudflare Workers로 운영하는 무료 체험 서버를 거쳐 외부 AI 제공자(Cloudflare Workers AI, 필요하면 Google Gemini·Groq)로 전송됩니다. 서버는 프롬프트와 응답 본문을 저장하지 않고, 방문자 구분용 해시값과 그날의 사용 횟수만 남깁니다(7일 뒤 삭제). 하루 무료 횟수는 브라우저당 5회이며, 다 쓰면 안내와 함께 내 키 연결로 넘깁니다. 이 버튼을 쓰지 않으면 서버로 나가는 내용은 없습니다. 영상·사진·음성 파일은 어느 경우에도 전송되지 않습니다.

3. Pro 기능을 연결했을 때

사용자가 직접 API 키를 넣고 연결한 경우에만, 버튼을 누른 순간 아래 내용이 해당 제공자에게 전송됩니다.

기능전송 내용
AI 대본주제, 톤, 플랫폼, 추가 요청 문장
AI 컷 이미지대본에서 만든 장면 설명(영문 프롬프트)
AI 성우내레이션 문장, 발화 속도

받은 성우 음성은 컷 길이·자막 타이밍을 맞추는 데 쓰고, 영상 녹화가 끝나면 메모리에서 사라집니다. 앱 서버에는 저장하지 않습니다.

제공자는 사용자가 선택한 곳입니다: OpenAI, Google Gemini, Anthropic Claude, 또는 사용자가 입력한 자체 API 서버. 각 제공자의 이용약관과 개인정보 처리방침이 함께 적용됩니다. 앱은 키를 자체 서버로 보내지 않으며, 키를 화면에 다시 표시하지도 않습니다(마스킹만 표시).

4. 쿠키와 추적

쿠키를 쓰지 않습니다. 접속 통계·광고·행동 추적 스크립트를 넣지 않습니다. 사이트를 정적 호스팅(GitHub Pages)에 올린 경우, 호스팅 사업자가 접속 로그(IP 등)를 남길 수 있으며 이는 앱이 통제하지 않습니다.

5. 사용자가 직접 지우는 방법

  • Pro 키: Pro 연결 화면의 연결 해제 또는 탭 닫기
  • 프로젝트·사진: 브라우저 설정에서 이 사이트의 저장 데이터 삭제
  • 완성 파일: 다운로드 폴더에서 직접 삭제

6. 아동의 개인정보

만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

7. 변경 안내

방침이 바뀌면 이 페이지에 시행일과 함께 게시합니다. 중요한 변경은 앱 화면에서도 알립니다.

8. 문의

이 앱은 개인이 만든 무료 도구이며, 문의는 앱을 배포한 저장소의 이슈 페이지로 받습니다. 개인 이메일·전화번호는 공개하지 않습니다.
