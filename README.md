# 원탭 숏폼 스튜디오 (One-Tap Shorts Studio)

대본 한 줄(또는 주제 하나)로 **9:16 세로 숏폼 스토리보드 5컷**을 만들고,
**AI 멀티에이전트 NLE 타임라인**에서 컷·자막·색보정·오디오를 다듬은 뒤
브라우저에서 **실제 영상 파일(.webm)** 로 녹화해 내려받는 웹앱입니다.

- 무료 모드: API 키·서버 없이 100% 동작. 대본 분배, 컷별 **자동 비주얼(그래픽 일러스트)**, 테마 6종, NLE 타임라인, 색보정, 자막, 배경음 합성, 영상 녹화가 모두 브라우저 안에서 끝납니다. 브라우저 음성으로 **무료 미리듣기**와 **발화 속도 기반 타이밍**도 쓸 수 있습니다.
- Pro 모드(선택): OpenAI · Google Gemini · Anthropic Claude · 자체 API 서버를 연결하면 **AI 대본 · AI 컷 이미지(5컷 일괄) · AI 성우**에 더해, 성우 음성의 **실제 길이에 컷·타임라인·자막을 1:1 자동 싱크**하고 그 음성을 미리보기와 `.webm`에 **믹싱해 녹음**합니다. 스웜 자동 편집도 실제 API 응답으로 타임라인을 채웁니다.
- **⚡ AI 원클릭 자동 완성**: 대본 → 비주얼(Pro면 AI 이미지 5컷) → 성우 음성(Pro) → 자막 싱크를 버튼 한 번으로 순서대로 돌립니다.

정적 파일만으로 돌아가며, GitHub Pages 같은 곳에 그대로 올릴 수 있습니다.

## 1. 무엇이 나오나

| 결과물 | 설명 |
|---|---|
| `.webm` 영상 | 1080×1920 / 720×1280 / 540×960, 30·24fps, VP9(+Opus). 배경음과 **성우 내레이션**이 각 컷 시작에 맞춰 믹싱된 실제 녹화 |
| `.srt` / `.vtt` 자막 | 컷 시간에 맞춘 자막. 17자 단위로 끊어 세로 화면에 맞춤 |
| 컷 PNG 5장 | 컷별 대표 프레임(1080×1920). 썸네일·카드뉴스용 |
| 썸네일 PNG | 첫 컷 중간 프레임 |
| 대본 `.txt` | 제목·보조 문장·연출 지시 |
| 캡션 | 첫 컷 훅 + CTA + 해시태그. 클립보드 복사 |

영상은 서버로 가지 않습니다. 녹화·인코딩·저장이 모두 사용자의 브라우저에서 일어납니다.

## 2. 5컷 구조

| 컷 | 역할 | 기본 길이 | 핵심 |
|---|---|---|---|
| 01 훅 | 3초 안에 멈추게 | 3.8초 | 인사말 금지, 숫자·반전·손실로 시작 |
| 02 문제 | 겪는 불편을 짚기 | 4.6초 | 해결책은 아직 말하지 않기 |
| 03 해결 | 방법·제품 한 문장 | 5.2초 | 과정은 3단계 이내 |
| 04 증거 | 숫자·후기·비교 | 5.0초 | `[숫자]`는 실제 값으로 교체 |
| 05 행동 | 저장·팔로우·클릭 하나 | 3.6초 | 행동은 하나만 |

컷 길이는 0.8~15초 사이에서 직접 조절합니다. 합계 20초 안팎이 완주율에 가장 좋습니다.

## 2-1. NLE 워크스페이스 (AI 멀티에이전트)

`영상 스튜디오` 탭은 프로그램 모니터 · 스코프 · 컬러 · 멀티트랙 타임라인을 갖춘 편집 베이입니다.

| 영역 | 내용 |
|---|---|
| SOURCE | 9:16 프로그램, 배경음(A1), 자막(T1) 소스 카드 |
| SWARM ACTIVITY | Claude(대본/자막) · Gemini(컷/리듬) · GPT(색보정/사운드) 상태와 실시간 편집 로그 |
| PROGRAM | 9:16 실시간 프리뷰, 재생/일시정지, `00:00:00:00` 타임코드, 안전 영역 |
| SCOPE · COLOR | 실시간 오디오 파형·스펙트럼, 컬러 휠(온도·틴트), 노출·대비·채도·온도 슬라이더, 프리셋 6종 |
| TIMELINE | V1 영상 · T1 자막 · A1 오디오(파형·비트) · FX 효과 트랙, 클립 선택·길이·문장 편집 |
| EXPORT | 해상도·프레임·배경음·전환·핸들, .webm 녹화, .srt/.vtt/PNG/TXT/캡션 |

**🤖 AI 스웜 자동 편집 실행**을 누르면 세 커서가 타임라인과 프리뷰 위를 실제로 이동하며
`컷 분할 → 자막 배치 → 색보정 적용 → 오디오 싱크`를 순서대로 적용합니다.
무료 모드(키 없음)는 테마·문장 길이·비트를 읽는 **규칙 엔진**으로 즉시 동작하고,
Pro 연결 상태에서는 **API 응답(JSON)** 의 컷·분할 비율·색보정 프리셋을 우선 사용합니다(실패 시 규칙 엔진으로 폴백).

색보정은 캔버스에 바로 적용되어 **프리뷰·컷 PNG·.webm 녹화 프레임**이 같은 값을 씁니다.
T1 자막을 고치면 `.srt`/`.vtt` 내보내기에 그대로 반영됩니다.

## 2-2. 자동 비주얼 · 내레이션 싱크

| 기능 | 무료 모드 | Pro 모드 |
|---|---|---|
| 컷 비주얼 | 컷 문장의 키워드(숫자·돈·청소·음식·운동·비즈니스·시간·건강·집·공부·여행·주의)를 읽어 **1080×1920 Canvas 그래픽 카드**를 컷마다 그림. 큰 숫자·단위를 함께 표시 | `gpt-image-1`/Imagen으로 **5컷 AI 이미지를 순차 생성해 바로 삽입**("5컷 모두 AI 이미지로 채우기") |
| 성우 | 브라우저 `speechSynthesis` **미리듣기** + 한국어 발화 속도(음절·쉼표 휴지)로 **컷·자막 타이밍 자동 계산** | 컷별 TTS(`tts-1`/자체 `/tts`) → **음성 길이 + 0.25초 호흡**으로 컷 길이·V1/T1/A1 타임라인·`.srt`/`.vtt`를 1:1 재정렬 |
| 미리보기·녹화 | 배경음 선택 재생 | `AudioContext`+`MediaStreamDestination`으로 **각 컷 시작 시각에 성우 음성과 배경음을 믹싱**해 미리보기 재생 및 `.webm`에 실제로 녹음 |
| 원클릭 | 대본(규칙) → 비주얼 → 발화 타이밍 | AI 대본 → 자동 비주얼 → AI 이미지 5컷 → 성우 5컷 + 싱크 |

- 대본·길이를 바꾸면 타임라인과 자막이 즉시 다시 맞춰집니다(기존 T1 문구는 유지한 채 컷 안에서만 재배치).
- 사진·영상·AI 이미지를 직접 넣은 컷은 그 이미지가 우선하고, 자동 비주얼 카드는 그리지 않습니다.
- 무료 미리듣기 소리는 브라우저 제약상 **`.webm`에 녹음되지 않습니다**(화면에도 표시). 영상에 성우를 넣으려면 Pro 성우를 연결하세요.

## 4-1. 디자인 시스템 (Direction C · Dark Glass Studio)

영상 도구를 “영상 만드는 사람의 방”처럼 보이게 하는 다크 캔버스 시스템입니다.

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| canvas | `#06070B` (카드 바탕 `#111319`) | 화면 바탕·유리 카드의 불투명 폴백 |
| glass / edge | `rgba(255,255,255,.055)` / `rgba(255,255,255,.11)` | 유리 카드 배경과 1px 보더 |
| ink / sub / muted | `#F4F5F8` / `#ADB5C4` / `#949CAC` | 본문 / 보조 / 안내 |
| violet / teal | `#8B5CF6`(글자 `#B9A2FF`) / `#34E0C8` | 보라=상태·행동, 민트=성공·라이브 |
| radius / blur | 카드 20 · 입력 10 · 필 999 / blur 18~22px | 상단 바·히어로 모니터·스테이지 패널·모달에만 |

- **편집기 셸**: `#0B1120` 톤의 NLE 베이 위에 9:16 프로그램 모니터(타임코드 HUD · 안전 영역), 오디오 스코프, 컬러 휠/슬라이더, V1·T1·A1·FX 타임라인과 재생 헤드를 둡니다. 컷 목록은 단계별 색을 가진 클립 레일로 그립니다.
- **글로우는 화면당 2~3개**만(배경 라디얼 3개). 카드마다 글로우를 넣지 않습니다.
- **라이트 모드는 보조**: 토글은 있지만 정체성은 다크입니다. 라이트는 표·긴 글을 읽기 위한 고대비 인쇄 모드입니다.
- `prefers-reduced-motion` · `prefers-reduced-transparency` · `backdrop-filter` 미지원 브라우저에서는 blur·글로우를 끄고 불투명 바탕으로 떨어집니다.
- 대비는 `node test.js`의 ‘디자인 토큰 C안’ 그룹이 본문·보조·라벨·포인트 글자(다크/라이트 8쌍)를 WCAG 2.2 공식으로 검사합니다.


`uitest.py`는 앱 폴더를 127.0.0.1로 띄우고, 데스크톱 1440×900과 모바일 390×844에서
외부 요청 0건, 콘솔 에러 0, 가로 넘침 0, NLE 트랙 4개·클립 선택/길이/자막 편집,
색보정 슬라이더→프리뷰 반영, AI 스웜 자동 편집(커서 이동·컷 분할·자막·색보정·비트)과
Pro BYOK 스웜(모의 API), MediaRecorder Blob 생성, **내보낸 .webm 프레임의 색보정 반영(PCM 평균 비교)**,
`.webm` EBML 헤더·길이, `.srt`(T1 편집 반영), PNG 5장, Pro 모달 순서·연결·해제,
새로고침 후 색보정 유지, 다크/라이트 대비, 개인정보 페이지를 확인합니다.

내레이션·비주얼 업그레이드는 모의 TTS 응답(1.6초 WAV)으로 다음을 실제 브라우저에서 검증합니다.

- 자동 비주얼 켜기/끄기 → 프리뷰·컷 칩 변화, 5컷 비주얼 정의

## 7. Pro 연결 (선택)

키를 넣지 않아도 앱은 100% 동작합니다. 연결은 반복 작업을 줄이는 선택 기능입니다.

| 순위 | 제공자 | 대본 | 이미지 | 성우 | 기본 모델 |
|---|---|---|---|---|---|
| 1 | OpenAI | ✓ | ✓ | ✓ | `gpt-4.1-mini` / `gpt-image-1` / `tts-1` |
| 2 | Google Gemini | ✓ | ✓ (Imagen) | – | `gemini-2.5-flash` / `imagen-4.0-generate-001` |
| 3 | Anthropic Claude | ✓ | – | – | `claude-sonnet-4-5` |
| 4 | 자체 API 서버 | ✓ | ✓ | ✓ | 직접 지정 |

- 키는 이 탭의 `sessionStorage`에만 저장되고 탭을 닫으면 사라집니다. 앱의 서버는 없습니다.
- 연결 확인은 각 제공자의 모델 목록 엔드포인트를 한 번 호출합니다.
- 일부 제공자는 브라우저 직접 호출(CORS)을 제한합니다. 그때는 자체 프록시 서버(4번)를 쓰세요.
- Claude는 브라우저 직접 호출을 위해 `anthropic-dangerous-direct-browser-access` 헤더를 사용합니다.

### 자체 API 서버 규격

`서버 주소` 아래 세 엔드포인트를 두면 됩니다. 인증이 필요하면 `Authorization: Bearer <키>`가 함께 갑니다.

```
POST {base}/script
  { "prompt": "...", "topic": "...", "tone": "friendly", "platform": "shorts", "model": "..." }
  → { "text": "..." }  또는  { "cuts": [{ "stage": "hook", "headline": "...", "sub": "..." }, ...] }

POST {base}/image
  { "prompt": "...", "size": "1024x1536", "model": "..." }
  → { "imageUrl": "https://..." } 또는 { "b64": "..." } 또는 { "dataUrl": "data:image/png;base64,..." }

POST {base}/tts
  { "text": "...", "voice": "nova", "model": "...", "speed": 1.08 }
  → audio/mpeg 바이너리

GET {base}/health
  → 200 (연결 확인용, 선택)
```

## 8. 보안·개인정보

- 무료 모드에서는 외부 요청이 0건입니다. 폰트·스킨·엔진까지 앱에 포함되어 있습니다.
- 업로드한 사진·영상은 브라우저 메모리와 localStorage에만 남습니다(영상에는 그대로 사용).
- Pro 키는 `sessionStorage`에만. localStorage·쿠키·서버로 보내지 않습니다.
- Pro 요청에는 대본 주제·톤·장면 설명·내레이션 문장만 들어갑니다.
- 자세한 내용은 `privacy.html`.

## 9. 알려진 제한

- **녹화는 실시간입니다.** 27초 영상은 27초 걸립니다. 테스트할 때는 540×960으로 낮추세요.
- 성우 음성을 만들면 컷 길이가 **음성 길이 + 0.25초**로 바뀝니다(0.8~15초 범위). 원래 길이로 되돌리려면 길이 슬라이더를 조절하거나 다시 대본을 만드세요.
- 무료 미리듣기(`speechSynthesis`)는 기기·브라우저마다 목소리가 다르고, **영상 파일에 녹음되지 않습니다**.
- MediaRecorder가 만드는 `.webm`은 길이 메타데이터가 비어 있을 수 있습니다(일부 플레이어에서 ∞로 표시). 업로드·재생에는 문제가 없고, 앱은 결과 미리보기에서 길이를 자동 보정합니다. mp4가 꼭 필요하면 편집 앱에서 변환하세요.
- Safari는 WebM 대신 MP4로 녹화될 수 있습니다(파일 확장자 자동 전환).
- 사진을 많이 넣으면 localStorage 용량(약 5MB) 때문에 자동 저장에서 이미지가 빠질 수 있습니다(영상에는 그대로 사용).
- AI가 만든 대본·이미지는 사실 확인과 권리 확인이 필요합니다. `[숫자]` 자리표시는 실제 값으로 바꾸세요.
